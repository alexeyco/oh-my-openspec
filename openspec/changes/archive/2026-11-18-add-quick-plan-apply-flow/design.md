# Design

## Approach

Add a fifth source flow skill, `skills/omos-quick/SKILL.md`, that owns the
combined workflow. The OpenCode command only prompts the current session and
binds that skill. The Codex renderer includes the same source skill in the
generated bundle and advertises its native skill mention.

The quick path is eligible only for exactly one externally observable behavior
in one capability, with no public API, architecture, data migration, or
security/privacy change. It performs one short interview and focused research
for that bounded request. It does not run the multi-round adversarial grill.
It still dispatches the planner and critic, requires `openspec_validate` to
return `VALID`, presents the compact plan for one user confirmation before
project-code edits, and then follows apply's implementation, scenario
verification, full checks, and cumulative diff review. It stops after review
and recommends the existing archive command without running it.

When the request contains multiple independent behaviors, is broad or spans
multiple capabilities, includes public API, architecture, data migration, or
security/privacy work, or has a material unresolved risk, quick switches to
the full plan/apply gates in the same invocation. The ordinary gates retain
their existing research, grill, confirmation, validation, implementation,
verification, and review behavior.

## Files to change

- `skills/omos-quick/SKILL.md` — shared quick-flow instructions.
- `core/prompts.ts` — quick command description and prompt builder.
- `opencode/index.ts` — add the quick command and skill id to OpenCode
  registration.
- `codex/skills.ts` — add the quick skill id to the Codex flow skill set.
- `README.md`, `docs/agents.md`, `docs/codex.md`, and `docs/using-both.md` —
  document the new command and Codex mention.
- `tests/assets.test.ts`, `tests/prompts.test.ts`, `tests/opencode.test.ts`,
  `tests/codex-skills.test.ts`, and `tests/codex-bundle.test.ts` — cover the
  flow asset, prompt, command, rendered skill, and generated bundle contents.
- `plugins/oh-my-openspec/skills/omos-quick/SKILL.md` — generated by
  `make codex`; do not edit by hand.

The OpenCode command continues to make one session prompt call and performs no
tool or Git operations. No archive behavior or data format is added.

## Trade-offs

The quick path reduces user interaction and command handoffs for bounded
changes, but it still creates a complete OpenSpec change and runs the same
implementation checks. Work that needs broad discovery or has unresolved
material risk loses the time savings by falling back to the full gates.
